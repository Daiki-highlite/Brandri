# ブランディングの費用相場｜依頼範囲・成果物・期間別に解説

ブランディングを外部へ依頼しようとすると、数十万円から数千万円まで、非常に幅のある見積もりが出てきます。

この差は、単純な会社の知名度だけで生まれるものではありません。「ロゴをつくる」のか、「経営や顧客を調査して価値を定義し、Webやプロダクトまで実装する」のかで、必要な専門性、人数、期間が大きく変わるためです。

この記事では、ブランディング費用を判断できるように、支援内容、成果物、予算別の考え方、見積書で確認すべき項目を整理します。

## ブランディング費用の目安

以下は一般的なプロジェクトを想定した目安です。実際の金額は、企業規模、調査対象、関係者数、制作物、納期によって変わります。

| 依頼範囲 | 費用の目安 | 主な内容 |
| --- | ---: | --- |
| 簡易的なコンセプト整理 | 30万〜100万円 | ヒアリング、ワークショップ、言語化 |
| ロゴ・VI開発 | 50万〜300万円 | ロゴ、カラー、書体、基本ガイド |
| ブランド戦略・言語・VI | 150万〜500万円 | 調査、戦略、コンセプト、コピー、VI |
| Webサイトを含む刷新 | 300万〜1,000万円 | 戦略、VI、撮影、Web設計・制作 |
| 新規事業・全社規模の支援 | 500万〜数千万円 | 調査、戦略、複数接点への実装、浸透・運用 |

金額だけを比べるのではなく、「何を決めるための費用か」「どの状態まで責任を持つか」を確認することが重要です。

## なぜ見積もりに大きな差が出るのか

### 制作前の調査・戦略が含まれているか

経営者へのヒアリングだけで進める場合と、社員、顧客、失注顧客へのインタビュー、競合調査まで行う場合では工数が異なります。

調査を省けば安くなりますが、社内の希望だけをきれいに表現し、市場での認識とずれるリスクがあります。

### 成果物の種類と数

ロゴ単体と、ロゴ、Web、UI、動画、営業資料、撮影を含むプロジェクトは比較できません。ページ数だけでなく、コピー開発、CMS、撮影、実装、アクセシビリティ対応などでも変わります。

### 意思決定に関わる人数

経営者一人で決めるプロジェクトと、複数部門・グループ会社・海外拠点の合意形成が必要なプロジェクトでは、会議設計や説明資料の工数が違います。

### 納品後の運用を含むか

ガイドライン納品で終わるのか、社内説明会、制作レビュー、コンテンツ運用、効果測定まで伴走するのかで費用は変わります。

## 項目別に見るブランディング費用

### 現状調査・顧客調査

経営・社員・顧客インタビュー、アンケート、競合分析、既存クリエイティブの棚卸しなどです。質問設計、実査、分析、報告まで含まれているかを確認します。

### ブランド戦略・コンセプト設計

ブランドの目的、顧客、提供価値、ポジショニング、ブランドパーソナリティなどを定義します。抽象的な言葉を納品するだけでなく、事業や顧客接点でどう使うかまで設計されていることが重要です。

### ネーミング・タグライン・コピー

候補案の数だけでなく、商標の簡易確認、ドメイン調査、ステークホルダー検証、多言語展開を含むかで変わります。

### ロゴ・VI

ロゴマーク、ロゴタイプ、カラー、書体、レイアウト、写真・イラスト方針、モーションなどを開発します。ロゴデータだけか、実際の利用例とガイドラインまで含むかを確認します。

### Webサイト・UIUX

情報設計、コピー、デザイン、撮影、実装、CMS、テストが主な項目です。SaaSやデジタルサービスでは、マーケティングサイトだけでなく、オンボーディングやプロダクト内の体験もブランドに影響します。

### 社内浸透・運用

社員向けワークショップ、ブランドガイド、テンプレート、レビュー体制、効果測定などです。新しい表現を現場が使えなければ、ブランドは公開直後から崩れていきます。

## 予算別に考える「できること」と「やらないこと」

### 50万円以内

すべてを刷新するのではなく、課題整理や短期ワークショップ、既存表現の診断など、次の投資判断に使う範囲へ絞ります。

この予算で戦略、ロゴ、Web、撮影をすべて高品質に行うのは現実的ではありません。

### 50万〜150万円

小規模な事業やサービスで、コンセプト整理とロゴ、簡易ガイド、主要ページのデザインなど、優先接点を限定した支援が考えられます。

### 150万〜500万円

経営・顧客へのヒアリング、ブランド戦略、言語、VI、主要なWebページや営業資料までを一貫して扱いやすい範囲です。

### 500万円以上

全社・複数事業のブランド体系、大規模な顧客調査、Webサイト全体、撮影・動画、複数拠点への浸透などを含むプロジェクトが対象になります。

予算が限られるほど、制作物を薄く広くつくるより、意思決定の核と最も重要な顧客接点へ集中すべきです。

## 見積書で確認したい10項目

1. プロジェクトの目的と成功条件が書かれているか
2. 調査対象と人数が明確か
3. ワークショップや会議の回数が明確か
4. 成果物の点数・ページ数・仕様が明確か
5. コピーライティングが含まれているか
6. 撮影、実装、開発、印刷が含まれているか
7. 修正回数と追加費用の条件が明確か
8. 商標調査や権利処理の範囲が明確か
9. 納品後の運用・レビューが含まれているか
10. 著作権、データ、フォントなどの扱いが明確か

「一式」という表記が多い場合は、何をもって完了とするのかを確認しましょう。

## 安さだけで選ぶと起こりやすい問題

- ロゴはできたが、顧客に伝える言葉がない
- Webと営業資料で表現が揃わない
- 誰が何を決めたのか分からない
- 修正のたびに追加費用が発生する
- 社内で使いこなせず、旧デザインに戻る
- 根本課題が解決されず、数年後に再度刷新する

高ければよいわけでもありません。重要なのは、自社の課題に対して必要な範囲が過不足なく設計されていることです。

## 内製と外注をどう分けるか

社内が持つべきものは、事業への意志、顧客情報、意思決定です。外部パートナーが支援しやすいのは、対話の設計、客観的な調査、言語化、専門的なデザイン、複数接点への実装です。

丸投げではブランドの中身が薄くなります。一方、すべてを内製すると、日常業務や社内関係に引っ張られて前提を問い直しにくくなります。社内外で一つのチームをつくる形が理想です。

## 費用対効果はどう測るか

売上だけをブランドの成果にすると、価格、営業力、市況など他の要因と分けられません。目的に合わせて複数の指標を設定します。

| 目的 | 指標の例 |
| --- | --- |
| 認知 | 指名検索、直接流入、想起率、SNS言及 |
| 営業 | 商談化率、受注率、営業説明時間、失注理由 |
| プロダクト | 利用開始率、継続率、解約理由、NPS |
| 採用 | 応募数、指名応募、承諾率、入社後のギャップ |
| 組織 | 理念理解、意思決定速度、制作工数、表現の一貫性 |

実施前の数値を記録しておかなければ変化を判断できないため、プロジェクト開始時に測定方法を決めます。
