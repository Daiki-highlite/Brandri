コアバリュー（中核的価値観）

Core Values

組織が判断や行動の拠りどころとする中核的な価値観。何を大切にするかの共通の芯を示す。

意味

コアバリューとは、組織が判断や行動の拠りどころとする中核的な価値観を指す。何を大切にし、何を良しとするのかという、組織に共有された芯にあたる。日本語では中核的価値観と訳される。

この価値観は、日々の意思決定の場面で効いてくる。迷ったときに何を優先するか、どんな振る舞いを是とするかを照らす基準となり、人が増えても判断の方向がぶれにくくなる。

コアバリューは、飾りの言葉として掲げるだけでは根づかない。採用や評価、日々の行動と結びついて初めて、組織の文化として生きてくる。掲げることと体現することの一致が問われる。

成り立ち

core values は「中核的な価値観」を意味する語で、組織が拠りどころとする根本の信条を指すようになった。

理念を日々の行動へと橋渡しする必要が意識される中で、判断や振る舞いの基準となる価値観を明文化する発想として広まった。

コアバリュー（中核的価値観）とMVVの違い

MVVは目指す先、存在の意義、価値観の三つを組にした枠組みであり、コアバリューはそのうち価値観にあたる部分を指す。全体と一部の関係にあるため、並べて論じると層がずれる。三つの中でどれを扱っているのかを先に定めると議論が噛み合う。

働く場面も違う。目指す先は向かう方向を示し、価値観は日々の選択で何を優先するかを示す。遠くを指す言葉だけでは目の前の判断は決まらず、優先の順序だけでは向かう先が決まらない。どちらが不足しているかで、書き足す層が変わることになる。

コアバリュー（中核的価値観）と企業文化（カルチャー）の違い

企業文化は実際に組織で共有されている振る舞いや空気であり、コアバリューは掲げた価値観の側にある。掲げた言葉が文化として根づくとは限らず、両者が食い違っている状態は珍しくない。原因と結果というより、宣言と実態の関係にあたる。

確かめる向きは、実態の側から言葉を見るほうが早い。何が実際に評価され、何が黙認されているかを並べると、掲げた言葉との差が見える。差が大きい場合、直す対象は言葉ではなく、評価や採用の運用のほうにあることが多い。

使いどころ

コアバリューは、組織が大切にする価値観を定め、判断や行動の基準にする場面で用いられる。何を優先するかを言葉にして共有する。

企業文化やブランドパーパスの議論と結び付けると、掲げる価値観を日々の行動へつなぐ道筋を捉えやすくなる。

実務でのチェックポイント

  • 掲げた項目の反対を掲げる会社が成り立つかを一つずつ試す。成り立たないなら、判断の基準としては働いていない。
  • 掲げた価値観を守るために断った取引や、途中で降りた案件を思い出してみる。何も出てこない価値観は、まだ何かを捨てる基準として使われていない。
  • 昇進を決めた理由や評価シートの項目に、掲げた言葉が一つも出てこないなら、価値観は掲示物のままである。人事の制度に接続されて初めて、日々の判断へ降りてくる。
  • 価値観に反する振る舞いが実際に指摘された場面があるかを確かめる。指摘が起きていないなら、基準として使われていない。

よくある誤解

誠実さや挑戦といった、反対を掲げる企業が存在しない言葉が選ばれやすい。反対が成り立たない言葉は判断の基準にならず、迷った場面で何を優先するかを示せない。価値観として働くのは、それを守ることで何かを諦める場面が具体的に想像できる言葉のほうになる。

数を増やして網羅しようとする失敗も起きる。挙げた項目が多いほど、どの場面でも都合のよい項目を後から選べてしまい、優先の順序を示す機能が失われる。全部大事だという状態は、実質的に何も決めていないのと変わらず、判断の速さにも寄与しない。

よくある質問

コアバリューはいくつくらいが適切ですか？

迷った場面で優先の順序を言える範囲に収まるかどうかが目安になる。項目が並びすぎると、下した判断に合う価値観を後から拾ってこられてしまい、基準ではなく言い訳の材料へ変わる。数を決めるより先に、誠実さと速さのように衝突しうる二つを取り出し、どちらを上に置くかを言葉にできるかを試すほうが早い。

コアバリューは経営者が決めるべきですか？

決裁の側が引き受けることになるが、社員から集めた材料なしでは実態から離れやすい。すでに組織の中で良しとされている振る舞いを拾い上げ、その中から意図して残すものを選ぶ形にすると、掲げた瞬間から実例が存在する状態にできる。

掲げた価値観が守られていないときはどうすればよいですか？

言葉を直す前に、守らなかった振る舞いがどう扱われたかを確かめることになる。指摘されず結果だけが評価されているなら、実際の基準は別のところにある。掲げ直しても運用が変わらなければ同じことが繰り返されるため、先に手を入れるのは評価の側になる。
