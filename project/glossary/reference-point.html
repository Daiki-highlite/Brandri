参照点

Reference Point

人が価値や損得を判断する際に基準とする水準。良し悪しは絶対値でなくこの点との差で決まる。

意味

参照点とは、人が何かの価値や損得を評価するときに、基準として置く水準のことである。満足や不満は絶対的な量ではなく、この参照点からの差として感じられるとされる。

たとえば同じ価格でも、以前より高いか安いか、周囲と比べて得か損かによって受け取り方が変わる。判断は常に何かとの比較のうえで行われる。

ブランドや価格の設計では、顧客がどこを基準に見ているかを意識することが要点になる。参照点をどう置いてもらうかで、同じ提供内容の見え方が変わりうる。

成り立ち

参照点は、人の意思決定が絶対的な結果ではなく基準点からの変化として評価されるとする行動経済学の議論のなかで用いられてきた概念である。

英語の reference point は「基準となる点」を意味し、損得の感じ方が基準の置き方に左右されることを説明する語として定着した。

参照点とフレーミング効果の違い

フレーミング効果は、同じ内容でも示し方によって受け取り方が変わるという現象を指す。参照点は、その受け取り方を決めるときに置かれる基準そのものにあたる。示し方を変えることが、どの基準を思い浮かべさせるかを変えている、という関係になる。

切り分けたいときは、変えているものが何かを問うとよい。表現や枠組みを操作しているならフレーミングの話で、比較の相手そのものを問題にしているなら参照点の話になる。同じ提示でも、受け手がすでに別の基準を持っていれば、意図した効果は現れない。

参照点と知覚品質の違い

知覚品質は、受け手が感じ取る品質の水準そのものを指す。参照点は、その水準を判断するときに用いられる比較の基準にあたる。同じ品質でも、何と比べているかによって高くも低くも感じられるという形で、両者はつながっている。

実務での違いは、動かせる対象に表れる。品質の感じ方を上げるには、根拠や見え方といった提供の側に手を入れる。参照点に働きかける場合は、何と比べてもらうかという比較の枠組みに手を入れる。同じ課題に見えても、打つ場所が違う。

使いどころ

参照点は、価格提示やオファーの設計を考える際に「顧客は何と比べて判断するか」を検討する視点として使われる。

アンカリングや損失回避といった関連する現象と併せて論じられることが多く、価値の伝え方を左右する前提として扱われる。

実務でのチェックポイント

  • 商談の記録から、見込み客が自社と並べて検討していた相手の名を書き出す。想定していた比較先と顔ぶれがずれていれば、価格の見せ方の前提から立て直す。
  • 価格を提示した際に返ってくる第一声を集める。高いという反応の背後にある比較対象が何かまで踏み込んで聞く。
  • 提示資料に比較の手がかりを置いているか。何も示さずに価格だけを出せば、相手は自分の手元にある別の相場を持ち込み、そこからの差で得か損かを決める。
  • 値上げや条件変更の際、直前の水準が基準として残ることを見込んだ説明を用意しているかを確認する。

よくある誤解

参照点は送り手が自由に設定できる、という受け取り方が起きやすい。実際には、受け手はそれまでの経験や周囲の相場からすでに基準を持っており、提示された比較対象が納得されなければ参照点は動かない。示せるのは候補であって、採用するかどうかは相手の側にある。

高い基準を先に見せれば有利になる、という単純化も広く見られる。基準として不自然な対象を持ち出すと、比較の妥当性そのものが疑われ、提示全体の信頼が下がる。基準として機能するのは、その相手が実際に検討しうる範囲に収まっている対象に限られる。

よくある質問

参照点は意図的に動かせますか？

候補を示すことはできるが、採用するかどうかは相手の判断になる。妥当だと受け入れられる範囲の比較対象を示し、なぜその比較が適切かを説明できれば、基準として働く余地が生まれる。無理に高い対象を持ち出すと、比較そのものが疑われ判断を渋らせる。

値上げのときはどう扱えばよいですか？

直前の価格が基準として残ることを前提に設計する。据え置きの期間が長いほど、その水準が当然の基準として定着している。提供内容の変更を伴わない改定は差だけが意識されるため、何が変わったのかを併せて示せるかどうかで受け止め方が変わる。

無料で提供したものは後から有料化しにくいですか？

しにくくなる。無料という水準が基準として定着すると、その後のどの価格も上昇として受け取られる。最初から価格を示したうえで期間や範囲を限る形にすれば、基準は無料ではなく本来の価格の側に置かれるため、後の移行が緩やかになる。
