UX / CX / BX

UX / CX / BX

利用（UX）・顧客（CX）・ブランド（BX）の三層の体験設計。内側から外側に向かって一貫しているかが問われる。

意味

UX / CX / BXとは、体験設計を三つの層で捉える枠組みである。UX（利用体験）は製品やサービスを使う瞬間の体験を、CX（顧客体験）は購入前後を含む顧客としての一連の体験を、BX（ブランド体験）はブランドと出会うあらゆる場面の体験を指す。

三層は内側から外側へと入れ子の関係にあり、UXがCXの一部を、CXがBXの一部をなす。個々の画面の使いやすさ（UX）が、顧客としての満足（CX）を支え、それらの総和がブランドの像（BX）を形づくる、という広がりで捉えられる。

重要なのは、この内から外への層が一貫しているかどうかである。使い勝手だけを磨いてもブランドの約束と食い違えば、体験全体は分裂して感じられてしまう。

成り立ち

UX（User Experience）、CX（Customer Experience）、BX（Brand Experience）は、それぞれ別々に用いられてきた略語である。デジタル領域での体験設計が広がるにつれ、これらを利用・顧客・ブランドという同心円の三層として並べて論じる整理の仕方が用いられるようになった。

UX / CX / BXとカスタマージャーニーの違い

カスタマージャーニーは、顧客が辿る道筋を時間の順に並べた地図である。UX / CX / BXは、体験を範囲の広さで層に分けた枠組みで、時間ではなく入れ子の関係を表す。前者は順序を扱い、後者は視野の広さを扱うという違いになる。

併せて使うと抜けが見つけやすい。道筋の各段階で、どの層の体験が問われているかを重ねると、使い勝手だけを見ていればよい段階と、ブランドの像そのものが問われる段階の差が見えてくる。地図の上に層を敷く形で組み合わせる関係にある。

UX / CX / BXとサービスデザインの違い

サービスデザインは、体験を成り立たせる裏側の仕組みまで含めて設計する実務の呼び名である。UX / CX / BXは、その設計対象がどの範囲にあるかを示す整理の枠組みになる。何をするかを指す語と、どこを見るかを指す語という違いにあたる。

見分けたいときは、社内の体制が視野に入っているかを問う。応対の質が保てない原因が人員の配置や引き継ぎの仕組みにあるなら、それはサービスデザインの領域に入る。層の枠組みは、その原因がどの体験に響くかを説明できても、仕組みの側までは変えない。

使いどころ

「UXだけでなくCX・BXまで見る」といった形で、体験設計の視野を局所から全体へ広げる際に用いられる。個別の使いやすさの改善が、顧客体験やブランドの像とつながっているかを問い直す枠組みとして機能する。

実務でのチェックポイント

  • 直近の改善施策を三層のどれに効くもので仕分ける。一つの層に偏っているなら、視野がそこで止まっている。
  • 顧客の不満の声を、操作の問題、応対や手続きの問題、期待とのずれの問題に分類する。分類の偏りが弱い層を示す。
  • 購入前と購入後で担当する部署が変わる箇所を洗い出す。層のつなぎ目は、たいていその境目で切れている。
  • ブランドが掲げる約束の言葉が、画面の文言や応対の言い回しに実際に現れているかを確かめる。

よくある誤解

三層を内から外へ向かう段階と受け取り、使い勝手を整えてから顧客体験、最後にブランドという順に取り組むものだと扱われることがある。実際には入れ子であって順番ではなく、ブランドの約束が定まらないまま画面を磨いても、何を優先して整えるべきかの基準が出てこない。

略語を並べたことで視野が広がったと錯覚する誤りもある。三つの語を資料に書いても、実際に見ている指標が画面の操作性だけなら、扱っている範囲は何も変わっていない。層を増やしたなら、それぞれの層で何を観察するのかも別々に決まっていることになる。

よくある質問

UXとCXの境目はどこですか？

製品を使っている瞬間かどうかが目安になる。操作している間の体験がUXで、その前後の検討、購入、問い合わせ、解約までを含めるとCXになる。同じ不満でも、画面の中で起きたのか画面の外の手続きで起きたのかで、直す先はまるごと変わる。

BXまで見る必要があるのはどんな場合ですか？

接点が複数の部署に分かれている場合に必要になる。窓口ごとに応対の性格が違うと、顧客は同じ会社の話として受け取れなくなる。部署をまたいで同じ約束が守られているかを問うには、個別の体験より一つ外側の層から見る必要が出てくる。

三層すべてを同時に改善できますか？

同時には難しいが、順序の基準は決められる。外側の層で何を約束するかが決まっていれば、内側の改善で何を優先するかは導ける。逆に内側から積み上げていくと、個々の改善は進んでも全体として何を目指しているのかが説明できなくなる。
