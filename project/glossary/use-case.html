ユースケース

Use Case

利用者が製品やサービスを使って目的を達成する具体的な状況や筋道。誰が何のためにどう使うのかを一つの物語として記述したもの。

意味

ユースケースとは、利用者が製品やサービスを使って目的を達成する、具体的な状況や筋道を記したものである。「誰が」「何のために」「どう使うか」を一連の流れとして描き、抽象的な機能ではなく実際の使われ方から対象を捉え直す。

機能を並べる発想と対をなし、ユースケースは目的の側から設計を照らす。同じ機能でも、想定する状況が違えば求められる形は変わるため、どの場面を主に据えるかが設計の輪郭を決める。

構造の視点では、ユースケースは要求を具体の物語に翻訳する装置になる。関係者が同じ場面を思い描けることで、議論が抽象論に流れず、判断の基準が共有されやすくなる。

成り立ち

ユースケースは、ソフトウェア工学者イヴァー・ヤコブソン（Ivar Jacobson）がシステム開発の手法として体系化した概念に由来する。利用者とシステムのやり取りを記述する枠組みとして広まり、製品企画などにも応用されている。

使いどころ

「主要なユースケースを洗い出す」といった形で、想定される使われ方を具体化する場面で用いられる。機能の一覧ではなく、実際の状況から必要を導く際の起点となる。
