体験

経験価値

Experiential Value

製品の機能そのものではなく、それをめぐる体験を通じて受け手が得る価値。

意味

経験価値とは、製品やサービスの機能そのものではなく、それをめぐる体験を通じて受け手が得る価値を指す。何を手に入れるかだけでなく、どのように感じ、何を思い出として持ち帰るかに価値の源泉を見いだす考え方である。

この見方では、購入の前後を含む一連の体験が価値を形づくる。店の雰囲気、使うときの心地よさ、後に残る印象といった要素が、機能と同じかそれ以上に選ばれる理由になりうる。

機能や価格で差がつきにくい市場ほど、体験を通じて生まれる価値が重みを増す。ブランドが記憶に残る体験を設計する動機は、ここにある。

成り立ち

経験価値（experiential value）は、消費を機能や損得だけでなく体験の側面から捉える考え方の中で用いられるようになった概念である。バーンド・H・シュミットらの経験価値論がこの見方を広めたことで知られる。

モノの充足が進み、体験に価値を求める傾向が強まる中で、ブランドや消費を語るうえでの重要な観点として位置づけられるようになった。

経験価値と機能的価値／情緒的価値の違い

機能的価値と情緒的価値は、価値を二つの層に分けて捉える枠組みで、経験価値は時間の幅で価値を捉える見方にあたる。前者は何が提供されているかを分類し、後者は購入の前後を含む流れの中で何が残ったかを見る。分け方の軸そのものが違う。

重なる部分は多いが、扱う場面で使い分けられる。売り物の内容を整理するときは層で分けるほうが早く、どの瞬間に手を入れるかを決めるときは、流れとして捉えるほうが具体的な打ち手に届く。

経験価値とUX / CX / BXの違い

UXやCXは体験を設計し評価するための枠組みで、経験価値はその体験から受け手が得たものを指す。設計の側と、受け取られた結果の側という関係にあたる。動線を整えても、記憶に残るものが生まれていなければ、価値としては積み上がらない。

見分ける問いは、誰が判断するかにある。体験の設計の良し悪しは、使いやすさとして作り手の側でも検証できるが、価値が生まれたかどうかは受け手の側にしか現れない。滞りなく終わった体験が、何も残さないことはよくある。

使いどころ

経験価値は、機能を超えて体験そのものの価値を高める場面で用いられる。どの瞬間にどんな感情や記憶を残すかを設計の対象にする。

サービスデザインやゲーミフィケーションの議論と結び付けると、体験を価値へと変える具体的な手立てを描きやすくなる。

実務でのチェックポイント

  • 顧客に、自社を使ったときのことで覚えている場面を尋ねる。挙がらないなら、体験は流れているが残っていない。
  • 購入の前後を時間順に並べ、感情が動く場面がどこにあるかを書き出す。全て平坦なら、差は生まれにくい。
  • 二度目以降の利用で初回と同じ演出が繰り返されていないかを確かめ、回数が増えるほど負担になる要素を探す。
  • 直近の施策を、不便を取り除く改善と印象を残す工夫のどちらに手を入れてきたかで仕分ける。

よくある誤解

体験を良くするとは不便を取り除くことだ、と捉えられやすい。滞りのなさは不満を減らすが、それ自体は記憶に残りにくい。何も引っかからずに終わった体験は、後から思い出す手がかりを持たないため、次に選び直すときの理由にはなりにくい。

特別な演出を足せば経験価値が生まれる、という見方もある。日常的に繰り返し使われるものでは、非日常の演出はかえって邪魔になり、二度目以降は負担として受け取られる。使われる頻度によって、何が良い体験かは逆向きになりうる。

よくある質問

経験価値は測れますか？

金額として測るのは難しいが、痕跡は追える。使ったときのことを覚えているか、その場面を人に話したか、次に選ぶときの理由として挙がるかを尋ねると、残ったかどうかは見当がつく。満足度の数値だけでは、記憶に残ったかまでは分からない。

BtoBでも経験価値は関係しますか？

関係する。導入や運用の過程で担当者が感じた負担や安心は、次の更新や社内での推薦に効く。取引の内容が同じでも、進め方の印象が違えば選び直しのときの言葉が変わる。個人向けと違うのは、体験する人と決める人が分かれる場合がある点になる。

価格の安い商品でも体験は作れますか？

作れる。手をかける量ではなく、どの瞬間に何を残すかの選び方で決まる部分が大きい。包装を開ける瞬間や、困ったときの応対など、費用をかけずに印象が動く場面は残っている。全体を厚くするより、一点に絞るほうが安価な商材とは相性がよい。
