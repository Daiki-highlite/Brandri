想起集合（考慮集合）

Consideration Set

顧客が購買を検討する際に、実際に候補として頭に思い浮かべる少数のブランドの集まり。

意味

想起集合とは、顧客が何かを買おうとするとき、実際に候補として思い浮かべる少数のブランドの集まりのことである。考慮集合とも呼ばれる。

人はカテゴリー内のすべての選択肢を比べるわけではない。頭に浮かぶ数個の候補の中から選ぶため、そもそもこの集合に入っているかどうかが選ばれる前提になる。

想起集合に含まれていないブランドは、いくら実力があっても検討の土俵に上がらない。まず思い浮かぶ存在になることが、選ばれる手前の関門とされる。

成り立ち

consideration set は「検討の集合」を意味する英語で、購買時に候補として考慮されるブランド群を指す。人がすべての選択肢ではなく限られた候補から選ぶという理解に基づく。

想起集合・考慮集合という呼称は、記憶から呼び起こされ候補として残るブランドのまとまりを表す語として、消費者行動の議論に定着した。

想起集合（考慮集合）と純粋想起の違い

純粋想起は、カテゴリーを示されて名前が浮かぶかどうかを見る。想起集合は、実際に買おうとする場面で候補として残るかを指す。思い出せることと、候補に入ることは同じではない。

両者が食い違う場面に意味がある。名前は挙がるのに候補に入らない場合、記憶の弱さではなく、選択肢として真剣に検討する理由が欠けている。露出を増やす打ち手では動かず、候補に値する理由の側を扱うことになる。

想起集合（考慮集合）とメンタルアベイラビリティの違い

夜食を探すとき、贈り物を選ぶとき——そうした場面のどれだけで思い浮かぶかという広がりを測るのがメンタルアベイラビリティである。対して想起集合が指すのは、いま目の前にある一つの購買場面で実際に頭へ並んだ顔ぶれのことだ。場面をまたいで積み上がる力か、その一場面の顔ぶれかという違いになる。

見る単位が違うため、打ち手も分かれる。多くの場面で浮かぶようにするには、結びつける手がかりの数を増やす作業になる。特定の場面で候補に残るには、その場面で比較される条件に応えられているかが問われる。

使いどころ

想起集合は、ブランドが購買の検討段階でどれだけ候補に入っているかを捉える際に使われる。認知の先にある「候補入り」を問う視点になる。

純粋想起や第一想起、メンタルアベイラビリティといった概念と関連づけて論じられ、選ばれる前提としての存在感を測る枠組みの一部をなす。

実務でのチェックポイント

  • 直近の商談で顧客が同時に検討していた相手を具体的に挙げ、想定と一致するかを見る。
  • 顧客が候補を絞る際に使った条件を尋ね、自社が外れる場面がどこかを特定する。
  • 候補に入らなかった案件について、そもそも検討の対象になっていたのかを確かめる。
  • 候補に入る場面と入らない場面の違いを、用途や予算の規模で分けて整理する。

よくある誤解

候補に入っていれば、あとは比較で勝てばよいと考えられがちだが、集合に入る理由と選ばれる理由は別に働く。入るためには思い出されやすさが要り、選ばれるためには比較の条件で優位が要る。同じ施策で両方を満たそうとすると、どちらにも届かないことがある。

集合の大きさを増やすことが目標にされる場合もある。だが候補が何個になるかは買い手の側の事情で、こちらが押し込めるものではない。むしろ候補が多い状態は比較が長引く合図でもあり、自社が入っているかどうかとは別の問題として扱うほうがよい。

よくある質問

想起集合にはいくつのブランドが入りますか？

カテゴリーや買い手の慣れで変わるものの、市場にある選択肢がそのまま並ぶことはない。頭の中で同時に比べられる顔ぶれには限りがあり、買い慣れた相手ほど候補は少数に固まっていく。だから問うべきは集合の大きさではない。目の前の案件で自社の名が挙がったのか、挙がらなかったのかを商談ごとに拾うほうが、打ち手に直結する。

想起集合に入るにはどうすればよいですか？

思い出されるきっかけと、候補に値する理由の両方が要る。買う場面と自社が結びついていなければそもそも浮かばず、浮かんでも比較の条件を満たしていなければ候補から外れる。どちらが欠けているかは、失注の理由を辿ると切り分けられる。

想起集合と実際の購入はどう関係しますか？

入っていることは前提であって、保証ではない。候補に並んだ後は、価格や納期、担当者との相性といった条件で絞られていく。ただし集合に入っていなければ、その比較の場に立つこと自体ができない。手前にある関門として位置づけられる。
