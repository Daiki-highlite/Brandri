ジャーニーマップ

Journey Map

顧客がブランドと関わる一連の過程を、行動・思考・感情とともに時間軸で可視化した図。

意味

ジャーニーマップとは、顧客がブランドと出会い、検討し、利用し、その後に至るまでの一連の過程を、時間軸に沿って可視化した図のことである。カスタマージャーニーマップとも呼ばれる。

各段階での行動だけでなく、そのときの思考や感情、接する接点までを並べて描く。全体を一望することで、どこに不満や離脱が生じているかを見つけやすくなる。

部門ごとに分断されがちな顧客体験を、一人の顧客の連続した歩みとして捉え直すための道具として使われる。

成り立ち

journey map は「旅の地図」を意味し、顧客がブランドと関わる一連の過程を旅になぞらえて描くことに由来する。

顧客体験を段階ごとに分断せず、連続した歩みとして捉える発想とともに、サービスデザインや顧客理解の実務で用いられるようになった。

ジャーニーマップとカスタマージャーニーの違い

カスタマージャーニーは顧客の側に実際に起きている過程そのものを指し、ジャーニーマップはそれを描き出した図である。現象と記述の関係にあたり、図を作った時点で過程を把握できたことにはならない。描いたものと起きていることは別に扱う。

取り違えは、図の完成を目的にしてしまう形で表れる。描かれた段階が実際の行動と食い違っていても、図の上では整って見えてしまう。確かめるべきは図の完成度ではなく、そこに置かれた段階が実在の顧客の足取りと一致しているかどうかになる。

ジャーニーマップとエンパシーマップの違い

エンパシーマップは、ある一時点の人物が何を見聞きし、どう感じているかを断面として捉える。ジャーニーマップは時間の経過に沿って並べる。前者に時間軸はなく、後者は時間軸そのものが骨格になっている点が最も大きな違いになる。

使い分けの目安は、知りたいことが状態なのか推移なのかにある。なぜこの場面で迷うのかを掘るなら断面の図が向き、どこで離脱が起きているのかを探すなら時間軸の図が要る。両方を一枚に詰め込むと、どちらの問いにも答えにくい図ができあがる。

使いどころ

ジャーニーマップは、顧客体験の全体像を関係者で共有し、改善すべき接点を特定する際に用いられる。

カスタマージャーニーやタッチポイント、サービスデザインの議論と結びつけて論じられ、体験を横断的に捉える道具として位置づけられる。

実務でのチェックポイント

  • 図に描かれた段階のうち、実際の顧客の記録や発言から確かめたものと、社内の推測で埋めたものを色分けする。混ざったままなら分ける。
  • 最後に更新した時期を確認する。商品や販路が変わっているのに図が当時のままなら、実態から離れている可能性が高い。
  • 図を見た営業や店頭の担当者に、自分の実感と違う箇所を指摘してもらう。現場と食い違う段階には、描き手の想定が入り込んでいる。
  • 図から導いた改善のうち、実際に着手されたものを挙げる。一つもないなら、共有の道具としては働いても意思決定には接続していない。

よくある誤解

関係者で議論して作った図を、顧客の実像として扱ってしまうことがある。社内の推測で埋めた段階は、社内で共有されていた前提が可視化されたものにすぎない。裏づけのある部分と推測の部分が混ざったまま配られると、後から検証されないまま既定の事実として引用されていく。

感情の起伏を線で描いた段階で、直すべき箇所が特定できたとみなす扱いも起きやすい。谷がどこに来るかは分かっても、なぜそこで気持ちが沈むのかは、線の上には書かれていない。谷は問いのありかを指すだけであり、原因は聞き取りや行動の観察から別途拾う仕事になる。谷を見つけた後に何を調べるかまで決めて、初めて図が働き出す。

よくある質問

ジャーニーマップは誰が作るのがよいですか？

部門をまたいで作るほうが実務では機能する。顧客の過程は担当が分かれたまま進むため、一部門だけで描くとその部門から見える範囲しか描かれない。作る過程で他部門の認識と食い違う箇所が出てくること自体が、この図の価値の一つになる。

顧客の種類ごとに何枚も作るべきですか？

枚数より、分ける理由があるかどうかで決まる。歩き方が明らかに違う相手であれば分けた意味があるが、段階の並びがほとんど同じなら一枚で足りる。分けた図の差分を説明できないのであれば、その分割は管理の手間だけを増やすことになる。

BtoBの長い検討過程でも描けますか？

描けるが、一人の旅路として描くと実態から離れる。法人の購買では関わる人が複数おり、登場する時点もそれぞれ違うためである。現場で不便を感じる人、比較検討を進める人、最後に予算を承認する人。この三者の関与が時間軸のどこで交差するかまで描き込むと、稟議が滞る場所が浮かび上がる。
